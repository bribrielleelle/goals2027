---
name: Fresh account workspaces
description: Product rule for planner account initialization and anonymous browser data.
---

Every new planner account starts with no pages, goals, or todos. Do not automatically attach anonymous browser data to an account; leave existing browser data untouched unless the user asks for an import.

**Why:** The user explicitly wants every account to start fresh and does not want the prior demo/browser workspace silently carried into an account.

**How to apply:** Initialize first-time accounts with empty planner collections and clean appearance settings. Keep any demo content behind an explicit user action, and never use browser-local data as an account's initial workspace.
